# claude-mods

A marketplace of mods and hook plugins for Claude Code, and the place where the owner decides which session extensions to install, adopt or build.

## Language

### Mods

**Mod**:
A Claude Code plugin made of function hooks, generic enough to serve any owner, with any one owner's workflow held in its options.
_Avoid_: Extension, add-on

**Hook plugin**:
A plugin made only of plain command hooks, carried in this marketplace beside the mods when such hooks meet the need.
_Avoid_: Classic plugin, hooks mod

### Choosing mods

**Portfolio**:
The ranked list of candidates with their verdicts, ordered by the owner's minutes saved per week.
_Avoid_: Backlog, roadmap

**Friction**:
A recurring moment in the owner's sessions where their time or the session's context is lost, or where they bridge a workflow seam by hand.
_Avoid_: Pain point, waste

**Candidate**:
A need or an existing extension under consideration for the owner's sessions, before it has a verdict.
_Avoid_: Idea, proposal

**Verdict**:
The ruling on a candidate: install, adopt, build or skip.
_Avoid_: Decision, rating

**Skip**:
The verdict that a candidate is not worth any work, recorded with its reason so it is not weighed again.

**Install**:
The verdict that a third-party plugin serves the need as published, so it is installed from its own marketplace unchanged.

**Adopt**:
The verdict that a third-party extension's idea is re-authored here as a generic mod, crediting its source.
_Avoid_: Fork, vendor

**Build**:
The verdict that a need with no fitting outside source gets a new extension written from scratch.
