# claude-mods

Claude Code mods (function-hook plugins), installed through one marketplace.

## Mods

- `smart-compact`: lets Claude compact its own context at a step boundary it picks, with its own instructions, then resume the work on its own. Reminders arrive at 60% and 80% of the auto-compact point. Interactive sessions only: a `-p` or SDK session cannot compact on request yet, so there the mod only adds its keep-list to automatic compactions.
- `gh-pane`: `/gh-pane` (run again to hide the pane, so one key binding such as `"ctrl+x g": "command:gh-pane"` shows and hides it), or the `Open gh-pane` button above the prompt (`Hide gh-pane` while the pane is up, each followed by the Nerd Font GitHub mark, which `/plugin configure` can blank where the terminal font has none), docks a pane of the session repo's open issues and PRs in run order: spec trees from sub-issues, blocked-by edges, claims and their ship runs, planning maps whose tickets close without a PR, and the needs-triage and needs-info lists. Its header links the repo and counts the ready rows and the open PRs against the cap, then running and stale ship runs when there are any, in the theme's error colour while a claim is stale and its warning colour at a full cap; seated inline above the prompt, where the pane shows a window of its lines, it adds `↓ N more` for the lines below. The last line says when the repo was read (`read at HH:MM`, or `reading…` during a read), and while the pane holds the keyboard a hint follows: `Tab moves · Enter presses · r refreshes · e expands all`, or `e collapses all` while expand all is on. Below the header, `refresh` (hotkey `r` while the pane holds focus) re-reads the repo now. Docked, the pane asks for the widest dock Claude Code gives. Each row fits a narrow dock on one line: a state glyph, its title cut at the edge, its labels as dots in their GitHub colours (the state labels left off), and a short tail. The glyph means one thing anywhere in the pane: `▶` ready now or a map's next ticket, `✓` `✗` `◌` `○` in a PR whose check runs passed, failed, are running or are none, `◆` all done, `⊘` blocked, `◐` claimed, `!` a stale claim, `◇` yours, and `·` a spec, map, untriaged or waiting issue; `●` is only ever a label dot. The tail says what the glyph does not: `PR #N`, `by #N` (or `by N` for several blockers), the assignees, `done/total`, or the state word, such as `spec 4/10` for an issue whose open sub-issues carry its work. A row's `▸` toggle expands it to its full title, a `blocked by` line listing every blocker, its labels as coloured chips, and a line of its assignees, last update (`just now` under an hour), comment count and milestone, each wrapped under the tree's rail; `expand all` (hotkey `e` while the pane holds focus) expands every row, issues arriving later included, and a `/clear` keeps what is expanded. Its buttons, framed, with `ship` and `next` as the primary ones, fill the prompt with `/ship N`, `/triage N`, a map's next ticket (`/wayfinder MAP N`), a request to release a stale claim, or a request to close an issue whose sub-issues are all closed (`all done`), and never send it. Two band buttons act on this session's own state instead: when a main-loop answer carries the merge-gate text and a PR link, `merge PR #N` (hotkey `m`) sends the merge reply as your own prompt, and once that PR reads as merged over REST, `clear + /ship N` (hotkey `n`) clears the session and runs the first ready row's command (one that does not start with `/` shows no button), and goes once the next turn ends. When a ship run merges on its own on a clean gate, its answer's merged line (`Merged on a clean gate:` with the PR link after it on that line) takes the same read, so `clear + /ship N` shows with no merge button. A hotkey fires only once the band holds focus (`ctrl+x` then `tab`, or a click), never from the prompt, where `m` types a letter; a click always works. Beside a pane seated inline in a short terminal, Claude Code 2.1.312 leaves the band no rows, so its button shows again once the pane is hidden or the terminal is taller. A `/clear` keeps the open pane's last read of the same folder on screen until the next one lands. It reads the repo through `git` and `gh api` (REST only), so `gh` must be installed and signed in. The label names (the map label included), PR cap, ship worktree layout, the band button's icon, the text each button fills, the merge-gate text, the merged text and the merge reply are options in `/plugin configure gh-pane@claude-mods`.

## Install

```sh
claude plugin marketplace add Gharib89/claude-mods
claude plugin install smart-compact@claude-mods
claude plugin install gh-pane@claude-mods
```
